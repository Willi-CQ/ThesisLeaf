# Bachelorarbeit – Projektordner

Dieses Projekt wurde mit der ThesisLeaf-Vorlage angelegt. Alles Wichtige steht im **LEITFADEN.md** (im Editor anklicken → Markdown-Vorschau).

Kurz:

1. Persönliche Angaben in `meta.tex` eintragen.
2. Kapitel in `kapitel/` schreiben – jede Datei ist ein Kapitel.
3. Literatur über das Literatur-Panel (DOI, ISBN, arXiv, URL) in `literatur.bib` importieren.
4. Bilder nach `abbildungen/`, Code nach `code/`.
5. Strg+Enter kompiliert; das PDF bleibt rechts sichtbar.

Nicht abgeben: `.local-overleaf/` (Build, Historie, Statistik).
